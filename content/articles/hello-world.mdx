# Hello World

这是 **saulyue.site** 的第一篇文章。

## 关于这个站点

这是一个用 Next.js 15 + Tailwind CSS 构建的个人微服务 Hub，承载：

- 个人主页 & 作品集展示
- 技术博客（MDX 文章系统）
- API 网关（BFF 层）
- 各子项目的统一入口

## 技术栈

```typescript
const stack = {
  framework: 'Next.js 15 App Router',
  styling: 'Tailwind CSS 4',
  content: 'MDX + gray-matter',
  deploy: 'Docker + Nginx',
  ci: 'GitHub Actions',
};
```
